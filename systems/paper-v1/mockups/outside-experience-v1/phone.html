Target: Phone · 393×852 · State 1 of 3 · Status: review · Updated 2026-09-17

Intent

The rulebook's first state. Nothing spatial is running, so there is no view to protect and the UI is allowed the whole screen — the only state where that is true. It is plain paper, because dressing up as a spatial surface before the experience starts misrepresents what the device is doing.

Why it is built this way

  • No web sign-in anywhere in the product: you join with a pairing code or pick a room. No password ritual in a hard hat and gloves.
  • The code is the largest element on the screen and set in the numeral face, because a hand face has no aligned figures.
  • Both actions sit in the bottom third, inside one-handed thumb reach on a 6.1 inch screen. The room list scrolls above them.
  • One required action, so exactly one button carries the ring. Under the rationed-colour rule nothing else on the screen can compete with it.

Open questions

  • Should a recently joined room be offered above the code entry, or does that invite rejoining a finished session?
  • Six digits is a generous target but a lot of typing. Is four plus a room pick enough on site?
