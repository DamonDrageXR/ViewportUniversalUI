Field AR — Layer Control

Target: iPad Pro landscape · Status: reference · Updated 2026-09-17

Intent

Reference example for the system: a one-handed field layout where the operator holds the iPad with one hand and drives everything with the other thumb. Tool rail on the left, layer tree on the right, telemetry centred and out of the way.

Why it is built this way

  • Every control is at least --hit-xr (64px) — this is used in gloves, in sun, on uneven ground.
  • Panels are translucent so the operator never loses sight of the site behind the UI.
  • Layer visibility is a toggle, not a tap-to-select, so no state is ambiguous at a glance.

Open questions

  • Does the tool rail belong on the left, or should it mirror for left-handed operators?
  • Is a flat layer tree enough, or do sites routinely need more than two levels of folder?
