Settings

Universal values for this system. Globals cascade into everything below them — the accent ramp, every surface, all four radius steps, the whole spacing and type scale, the line weights, and the hit-target floors.

Global settings

cascades to everything

The accent fill behind white text and the accent/status text colours are recomputed from these to clear 4.5:1, so a new brand colour cannot quietly drop a control below contrast.

Rules

structural

Decisions no value can carry — whether a treatment is allowed at all rather than what size or colour it is. These are what separate a system from a palette: two systems can share every token and still not be the same language. A rule set here applies to every component and every mockup built with this system.

Elements

Every component the system produces, live and interactive, with the settings above applied. This is the draft — it updates as you change a setting, before anything is saved.

Open the elements page on its own ↗ — useful for clicking through states at full width.

Mockups

One tile per mockup, holding a screen for each device it covers — phone, iPad portrait and iPad landscape are the targets that matter. They are in the Mockups view too, where they can be re-rendered with any system.
