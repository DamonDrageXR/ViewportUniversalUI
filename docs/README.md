## paper-system/

The Paper System — Viewport XR rulebook, skill and token CSS, verbatim, plus
the mapping from each Paper rule to the global, rule or override that carries
it in `systems/paper-v1`.

Read it before changing that system: it lists the four places the derived
tokens deviate from the source and why, so a "fix" does not quietly undo a
deliberate trade-off.
