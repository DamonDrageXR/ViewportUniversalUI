## paper-system/

The slot for the Paper System — Viewport XR documents. Copy the `.md` files
from `Downloads\Paper System — Viewport XR` into `docs/paper-system/` and
commit them.

Until they are in place, the `Viewport XR v1` system carries a placeholder
palette. Applying the real one is a change to that system's globals — see
[`paper-system/README.md`](paper-system/README.md).
